Ali Habil XP Portfolio

How to use:
1. Open index.html in a browser.
2. Edit project text in script.js.
3. Add future project images into assets/images/ using the placeholder filenames shown on each card.
4. Replace # links in script.js with real GitHub, Devpost, demo, report, photo, or CAD links.

Main files:
- index.html: page layout
- styles.css: Windows XP/off-white styling
- script.js: project data, category tabs, and popup details
- assets/images/: add your photos/screenshots later
